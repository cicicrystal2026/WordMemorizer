### 1.2 「统计式学习」——值得借鉴的一点

三个入口分别是 **自然拼读、词根词缀、音标组**。它们不是新词库，而是把同一册词
按**构词规律重新聚类**的三种视角：

- 自然拼读：按字母组合发音规律分组（适合低龄）
- 词根词缀：按 `pre-` `-tion` 等形态分组（适合高年级、高考）
- 音标组：按音素分组（服务发音训练）

命名为「统计式」说明分组是**从词库统计出来的**，不是人工编排。这是一个低成本、
高感知价值的功能——同一份词库免费多出三种学习路径。

对我们的启发：**高考 3500 词做词根词缀聚类，价值远大于低龄的自然拼读。**
我们已入库的 `data/gaokao-3500.json` 目前没有词根词缀字段，若要做需在补全阶段一并生成。

### 1.3 拍照阅读模块（本批重点）

这是竞品处理「用户自有材料」的通道，层级为：

```
拍照阅读
└── 阅读本（列表页，可有多本）        ← 「+ 添加阅读本」
    └── 单元 Unit1 / Unit2 …（Tab 横向排列）  ← 「+ 添加单元」
        └── 拍照导入（一个大按钮占位）
            └── 动作面板：拍照 / 从手机相册选择 / 取消
```

**阅读本列表页**：书本卡片（封面显示 `ENGLISH` + 书名 `11`），底部通栏
`+ 添加阅读本`；右上角 `?` 帮助 + 编辑图标（管理/删除）。第三张截图是同一页面的
**空状态**——白板一块，没有任何引导插图或说明文案。

**单元页**：
- 顶部：返回、书名 `11`、`⚠ 免责声明` 胶囊、右上角九宫格图标（推测为视图切换）
- 次级：`Unit1` 下划线选中态 + `+ 添加单元`
- 主体：`拍照导入` 大按钮
- **底部常驻播放条**：`1.0x` 倍速 / 上一条 / 播放 / 下一条 / `EN中` 语言切换

### 1.4 从这批截图能确认的三件事

**① 拍照导入的产物是「可播放的音频序列」，不是「可学习的单词」。**
底部播放条在**尚未导入任何内容时就已常驻**，说明单元页的本质是一个播放器。
`EN中` 切换推断为「只读英文 / 英中对照朗读」，`1.0x` 为语速。也就是说，这个模块
解决的是**跟读和磨耳朵**，而不是把拍下来的词纳入背诵体系。

**② 拍照阅读与主词库是两套平行体系，不打通。**
它挂在「单词书」页的四个快捷卡片里，是个附属工具。用户拍进去的词
**不会**进入主页那个「已学 48 / 未学 102」的进度环，也进不了 `学单词` / `去复习`
的循环。这是竞品的**结构性缺陷**。

**③ 只支持拍照和相册，不支持 Excel / PDF。**
动作面板只有两项。用户的孩子拿到的可能是老师发的电子表格或打印讲义，竞品覆盖不了。

### 1.5 「免责声明」说明的问题

单元页专门给免责声明留了一个常驻胶囊位。这几乎可以肯定是为了规避
**用户上传教材内页的版权风险**和 **OCR 识别错误导致的教学误导**。
我们做同类功能时同样会撞上这两条，需要在 PRD 里正面处理，不能忽略。

## 第 2 批（5 张）：拍照识别完整链路

### 2.1 链路还原

```
拍照导入 → 应用内相机 → 拍摄确认（X / ✓） → 智能识别中(9%)「请勿退出」 → 词条卡片列表
```

**① 应用内自建相机**（非系统相机）
顶部：返回、闪光灯开关、设置齿轮；底部：`W / 1x / 2x / 3.5x / 10x` 变焦档、
快门、前后摄切换。给了变焦说明他们知道用户常在**较远距离拍整页**。

**② 拍摄确认页**
只有 `X` 取消和 `✓` 确认两个操作，**没有裁剪框、没有透视校正、没有旋转**。
拍歪了只能重拍。

**③ 识别中**
`智能识别中，请勿退出...(9%)` —— 带百分比进度。「请勿退出」说明识别过程
**绑定前台、不可后台化**，退出即中断。见 2.4。

**④ 结果页**：竖向卡片列表，每张卡片两行 + 一行免责小字。

### 2.2 被识别的原始材料（重要）

拍的是**电脑屏幕上显示的扫描版 PDF**——「斯坦英语 - Unlock Your World with English」
第 121 页，双栏排版，编号 175–232，格式为 `175. indicate v.表明`。

这是个**极端不利的 OCR 场景**：拍屏幕（摩尔纹 + 反光 + 低对比度）、双栏、
带手写圈注。而识别结果准确——左栏 179–184（influence / initiative / innovation /
insight / inspire / install）与右栏 227–232（motivate / mutual / neglect /
nevertheless / notion / novel）都与原页逐条吻合。

可以确认他们做对的三件事：
- **双栏阅读顺序正确**：先左栏从上到下，再右栏，没有横向串行
- **序号被剥离**：`175.` 这类编号没有进入词条
- **抗屏摄干扰**：摩尔纹和反光没有击穿识别

这条基线要记住：**我们的识别质量至少要达到这个水平**，否则没有替换理由。

### 2.3 结果卡片的结构与缺陷

单张卡片：

```
influence v/n.影响          ← 第一行：原文识别结果（词 + 词性 + 中文）
影响                        ← 第二行：AI 解析出的中文释义
                内容由 AI 生成,仅供参考   ← 每张卡片都有
```

`novel adj.新颖的 n.小说` → 第二行归一化为 `新颖的；小说`，说明第二行确实经过
AI 解析和标点归一，不是简单复制。但在绝大多数词条上，**两行内容几乎完全重复**
（`影响` / `影响`、`创新` / `创新`），视觉上是纯冗余。

更关键的缺失：

- **没有音标**——卡片只有词形、词性、中文，与我们从 PDF 解析出的底库缺口一致
- **没有例句、没有词组**
- **看不到任何编辑入口**——不能纠正识别错误，只能被告知「仅供参考」

### 2.4 三个架构层面的观察

**① 识别是前台阻塞的。**
「请勿退出」+ 百分比进度 = 任务与前台生命周期绑定。拍一页要等，拍十页大概率
只能一页一页来。**我们应该做成服务端异步任务**，提交后可以退出，完成推送通知。

**② 出现了麦克风——但只在「当前项」上。**
结果页中 `insight n.洞察力` 整张卡片文字变**橙色高亮**，同时卡片右下角浮出一个
**麦克风按钮**；其余卡片没有。结合底部播放条，推断交互是：
顺序播放 → 播到哪张卡片哪张高亮 → 在当前卡片上可以录音跟读。

**这是全产品第一次出现录音入口。** 但目前只能确认「能录」，
**不能确认是否有评分/发音诊断**。这是后续批次要重点确认的（见待确认项）。

**③ 手写圈注被完全忽略。**
原页上 180、188、191、195、201、202、204、205、206、208、210、211、212、214、
216、219、227 等条目被笔圈了出来——这显然是使用者标记的重点词。
但结果列表里 179（未圈）和 180（圈了）一视同仁地全部导入，圈注没有被当作任何信号。

**这是一个明确的产品机会**，见下方差异化第 5 条。

### 2.5 顺带确认

拍的是高考词汇材料（编号已到 232，词汇难度为 legitimate / literacy / mediate 一档），
与用户给的 3500 词 PDF 属于同一学段。**我们选高考 3500 词作底库是对的。**

## 第 3 批（5 张）：遮盖机制、掌握度分级、单元学习

### 3.1 拍照阅读播放器的两个隐藏开关

**① 标注模式：`语法 | 词性 | 无`**
结果列表右上角有一个三段选择器，当前选中「无」。说明播放时可以给每个词条叠加
**语法分析**或**词性标注**。这是把一个「朗读器」往「精读器」方向推的功能。

**② 遮盖：`EN中` → `中`**
底部语言按钮不是简单的中英切换，而是**遮盖开关**。切到 `中` 之后，每张卡片的
英文行变成**灰色色块**，只剩中文释义可见——变成一个「看中文回想英文」的自测器。
播放状态下配合高亮，就是听音 + 看中文 + 自己回忆拼写。

此时麦克风依然只出现在高亮的当前卡片上，行为与第 2 批一致。

**这个改动很小，价值很高**：同一个列表页，靠一个开关就从「跟读」切换成「自测」。

### 3.2 单词表页（内置教材词库的主列表）

这是与拍照阅读平行的另一套界面，功能密度高得多：

| 位置 | 控件 | 作用 |
| --- | --- | --- |
| 标题栏 | `科学刷词 >` | 独立入口，推测为间隔重复刷词模式（**待确认**） |
| 标题栏 | `?` / 六边形图标 | 帮助 / 设置 |
| 第二行 | `Lesson 9 ⌄` | 单元切换 |
| 第二行 | `无遮盖 ⌄` | **遮盖模式选择器**，与 3.1 同源，此处是下拉多选项 |
| 筛选行 | `🚩重点词` | 重点词筛选（红旗） |
| 筛选行 | `全部 / 已学 / 未学` | 学习状态筛选 |
| 筛选行 | `🔖标签 ⌄` | 标签筛选，对应首页「标签本」 |
| 统计行 | `已学：5词` + `正序 ▽` | 计数与排序 |

**词条卡片结构**（与拍照阅读的卡片完全不同）：

```
┌────────────────────────┬──────────────┬─┐
│ [上次学习]              │              │ │
│ spring                 │ n 春天；春季  │3│ ← 右侧色条 + 数字
│ /sprɪŋ/                │              │ │
└────────────────────────┴──────────────┴─┘
```

- **有音标**（`/sprɪŋ/`、`/ˈsʌmər/`、`/ˈɔːtəm/`）
- `上次学习` 绿色角标标记断点，方便续学
- 右侧**彩色竖条 + 数字**：颜色表掌握度，数字表学习次数

### 3.3 掌握度分级——左滑手动改判（重要）

把 `summer` 卡片左滑，露出四个色块按钮：

| 按钮 | 颜色 |
| --- | --- |
| 生词 | 红 |
| 半熟 | 橙 |
| 熟悉 | 绿 |
| 永久掌握 | 黑 |

同一批截图里 `spring` 右侧数字从 `3` 变成 `5`，说明这个数字是**学习/复习次数**，
会随操作累加。

**关键点：掌握度是可以手动改判的。** 算法排的复习计划，用户可以一票否决——
「这个词我早就会了，别再考我」直接标永久掌握，「这个我其实没记住」打回生词。
这是间隔重复类产品**必须有**的逃生阀，否则算法一旦判错，用户只能忍受。

顺带一提：我们现有原型 `app/page.tsx` 首页那一排「没记住/刚学会/待巩固/已掌握」
用的正是红/橙/绿/黑同一套配色和四级分层，说明当初就是照这个抄的。

### 3.4 单元学习页（真正的学习环节，本批最有价值）

底部四个入口：`专项练习` / **`单元学习`** / **`学练一体`** / `情境美文`，
其中中间两个是实心主按钮，两侧是图标次要入口——优先级一目了然。

点进「单元学习」看到的是**单词逐个学习卡**：

- 顶部：词条 Tab 横排（spring / summer / autumn / winter / sea…），可直接跳词
- 右上三个图标：✍（推测为书写/笔记）、☆（收藏，对应收藏本）、六边形（设置）
- 主卡片自上而下：
  - **四线三格英语练习纸背景**上的大字 `spring`，其中 `spr` 蓝色描边、`ing` 灰色，
    **视觉化展示拼读切分**
  - 右上角一个**机器人吉祥物图标**（推测为 AI 助手入口，**待确认**）
  - `spring` 灰底胶囊
  - `[sprɪŋ] 🔊` 音标 + 发音按钮
  - `n. 春天；春季`
  - `完整翻译 ↻`
  - 两个模式按钮：`拆分发音`（描边）/ `自然拼读`（实心选中）
  - 分隔线以下为拼读拆解结果：`spr` `/spr/` 和 `ing` `/ɪŋ/` 两个音块
- 底部：🏷 标签、`✨ 加强学习`（主按钮）、`→` 下一个

**这里印证了第 1 批的判断**：首页「统计式学习」里的自然拼读不是独立词库，
而是一种**贯穿到单词学习页的展示模式**。`拆分发音` 与 `自然拼读` 是同一个词的
两种切分视角。

### 3.5 由本批可以确认的结构性结论

**内置词库与拍照词库是两套完全不同的实现，差距悬殊：**

| 能力 | 内置教材词库 | 拍照导入词库 |
| --- | --- | --- |
| 音标 | 有 | **无** |
| 掌握度分级 | 四级，可手动改判 | **无** |
| 学习次数统计 | 有 | **无** |
| 筛选（已学/未学/重点/标签） | 有 | **无** |
| 学习环节（单元学习/学练一体等） | 四种 | **无，只能播放** |
| 遮盖自测 | 有 | 有（仅中英遮盖） |
| 拼读拆解 | 有 | **无** |

第 1 批推断的「拍照词库进不了主学习循环」，到这批基本坐实：
**拍照进来的词，除了听和遮盖自测，什么都做不了。**

### 3.6 「重点词」概念已存在，但没有喂给它数据

单词表筛选行有 `🚩重点词` 红旗筛选项——**数据模型里本来就有「重点词」这个字段**。
但结合第 2 批的发现：拍照识别时满页的手写圈注被完全忽略。

也就是说，**他们有这个字段，却没有把最现成的数据源接上去**。
这让第 2 批提出的机会点价值更高：不是要发明一个新概念，而是把一条本该连上的线接上。

## 第 4 批（5 张）：单元学习的深度、词根助记、设置项

### 4.1 单元学习页的完整结构

第 3 批只看到骨架，这批看到了全貌。主卡片自上而下：

```
四线三格上的大字（音节分色，如 win·ter 深蓝/橙，su·mmer）
/ˈsʌmər/ 🔊  🎤          ← 音标发音 + 独立麦克风
n. 夏天；夏季
完整翻译 ↻
[拆分发音] [自然拼读]      ← 两种拆解视角，二选一
─────────────────────
（视图 A）音素块：/s/ /ʌ/ /m/ /ə/ /r/  +  /s/ ▶️ 🔍
（视图 B）拼读块：s /s/  u /ʌ/  mm /m/  er /ə/
─────────────────────
词根助记 卡片（并非每个词都有）
实用口语 卡片（可左右翻，多条例句）
```

**① 音素级拆解 + 口型视频**
`拆分发音` 视图把词拆成**可点击的音素块**（`/s/` `/ʌ/` `/m/` `/ə/` `/r/`），
末尾一个特殊块带 **▶️ 播放图标和 🔍 查询图标**——推断为该音素的
**口型示范视频**和音素详解。这是相当深的发音教学。

**② 自然拼读视图是字母→音的映射**
`s→/s/`、`u→/ʌ/`、`mm→/m/`、`er→/ə/`，字母与音标**用同色标记对应关系**
（s 蓝、u 红、mm 蓝、er 红）。与 `拆分发音` 的区别很清楚：
前者回答「这个词由哪些音组成」，后者回答「哪些字母发哪个音」。

**③ 词根助记（本批最值得借鉴的一项）**

```
┌─────┐   ┌─────┐   ┌────────┐
│ spr │ + │ ing │ = │ spring │
│ 散开 │   │     │   │  春天   │
└─────┘   └─────┘   └────────┘
      树叶散开的季节，即春天
```

每个词素块带 🔍 可下钻。注意这是**助记**而非严格词源学
（`spr = 散开` 在词源上站不住），目的是给记忆挂钩子，不是教语言学。
**这个取舍是对的**，我们做高考词时应沿用同样的实用主义。

并非每个词都有这张卡片——`summer` 就没有。说明是**按词供给**，不是强行凑。

**④ 实用口语（例句卡）**

```
Girls often wear dresses in summer .     ← 每个词不同颜色
女孩们夏天常穿连衣裙。
[🔊] [慢] [🎤] [AI]        ● ○ ○         ← 四个操作 + 页码点
```

- 例句里**每个单词染不同颜色**。结合第 3 批看到的 `语法|词性|无` 开关，
  推断是**词性着色**（待确认）
- 四个操作：正常播放 / 慢速播放 / **录音** / **AI**
- 页码点显示条数：`summer` 3 条、`winter` 5 条——**每个词的例句数量不等**

## 我们的差异化机会（滚动累积）

1. **上传的材料必须成为一等公民词书**——直接进入背诵与复习循环，而不是像竞品那样
   降级成一个只能听的播放器。这是用户最核心的诉求，也是竞品最大的空档。
2. **支持 Excel / PDF / 图片三种入口**，竞品只有图片。
3. **词根词缀聚类**用在高考 3500 词上，比竞品面向小学的自然拼读更有价值。
4. 识别结果**必须可人工纠错**（家长审核），这既是质量保证也是免责手段。
   竞品用「内容由 AI 生成,仅供参考」把风险转嫁给用户，我们应该用「可编辑」把它解决掉。
5. **识别手写圈注，作为重点词信号**（第 2 批发现）。老师或家长在讲义上圈出的重点，
   是现成的、高质量的优先级标注。竞品把这个信号整个丢掉了。
   实现上并不难——多模态模型可以直接被要求「标出哪些条目带手写圈注」。
6. **服务端异步识别**，替代竞品的前台阻塞式「请勿退出」。
7. **补齐音标**——竞品的拍照词条同样没有音标，而音标是听写和发音训练的前提。
8. **导入词库与内置词库共用同一套学习内核**（第 3 批发现）。竞品维护了两套实现，
   导致拍照词库功能残缺。我们只做一套：无论词从哪来，都有音标、掌握度、
   筛选、四级分层和完整学习环节。这既是产品优势，也是更省的工程方案。
9. **遮盖自测**（第 3 批发现）成本极低、价值很高，直接采纳。
10. **掌握度手动改判**（第 3 批发现）是间隔重复的必要逃生阀，必须做。

## 值得直接采纳的竞品设计（滚动累积）

- 遮盖开关：同一个列表页靠一个开关在「跟读」和「自测」之间切换
- 掌握度四级（生词/半熟/熟悉/永久掌握）+ 左滑手动改判 + 学习次数计数
- `上次学习` 角标标记断点，支持续学
- 学习状态筛选（全部/已学/未学）与自定义标签
- 拼读拆解的两种视角（拆分发音 / 自然拼读）——对高考词应替换为**词根词缀拆解**
- **词根助记卡**（第 4 批）：`spr 散开 + ing = spring 春天`，配一句白话解释。
  取实用主义、不追求词源严谨，是正确的取舍。按词供给，没有就不显示。
- 例句卡的四个操作（播放 / 慢速 / 录音 / AI）与多条例句翻页
- 发音人可选英音美音；两个字号滑杆（无障碍，成本极低）
