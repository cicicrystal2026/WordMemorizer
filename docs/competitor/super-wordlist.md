### 1.2 「统计式学习」——值得借鉴的一点

三个入口分别是 **自然拼读、词根词缀、音标组**。它们不是新词库，而是把同一册词
按**构词规律重新聚类**的三种视角：

- 自然拼读：按字母组合发音规律分组（适合低龄）
- 词根词缀：按 `pre-` `-tion` 等形态分组（适合高年级、高考）
- 音标组：按音素分组（服务发音训练）

命名为「统计式」说明分组是**从词库统计出来的**，不是人工编排。这是一个低成本、
高感知价值的功能——同一份词库免费多出三种学习路径。

对我们的启发：**高考 3500 词做词根词缀聚类，价值远大于低龄的自然拼读。**
我们已入库的 `data/gaokao-3500.json` 目前没有词根词缀字段，若要做需在补全阶段一并生成。

### 1.3 拍照阅读模块（本批重点）

这是竞品处理「用户自有材料」的通道，层级为：

```
拍照阅读
└── 阅读本（列表页，可有多本）        ← 「+ 添加阅读本」
    └── 单元 Unit1 / Unit2 …（Tab 横向排列）  ← 「+ 添加单元」
        └── 拍照导入（一个大按钮占位）
            └── 动作面板：拍照 / 从手机相册选择 / 取消
```

**阅读本列表页**：书本卡片（封面显示 `ENGLISH` + 书名 `11`），底部通栏
`+ 添加阅读本`；右上角 `?` 帮助 + 编辑图标（管理/删除）。第三张截图是同一页面的
**空状态**——白板一块，没有任何引导插图或说明文案。

**单元页**：
- 顶部：返回、书名 `11`、`⚠ 免责声明` 胶囊、右上角九宫格图标（推测为视图切换）
- 次级：`Unit1` 下划线选中态 + `+ 添加单元`
- 主体：`拍照导入` 大按钮
- **底部常驻播放条**：`1.0x` 倍速 / 上一条 / 播放 / 下一条 / `EN中` 语言切换

### 1.4 从这批截图能确认的三件事

**① 拍照导入的产物是「可播放的音频序列」，不是「可学习的单词」。**
底部播放条在**尚未导入任何内容时就已常驻**，说明单元页的本质是一个播放器。
`EN中` 切换推断为「只读英文 / 英中对照朗读」，`1.0x` 为语速。也就是说，这个模块
解决的是**跟读和磨耳朵**，而不是把拍下来的词纳入背诵体系。

**② 拍照阅读与主词库是两套平行体系，不打通。**
它挂在「单词书」页的四个快捷卡片里，是个附属工具。用户拍进去的词
**不会**进入主页那个「已学 48 / 未学 102」的进度环，也进不了 `学单词` / `去复习`
的循环。这是竞品的**结构性缺陷**。

**③ 只支持拍照和相册，不支持 Excel / PDF。**
动作面板只有两项。用户的孩子拿到的可能是老师发的电子表格或打印讲义，竞品覆盖不了。

### 1.5 「免责声明」说明的问题

单元页专门给免责声明留了一个常驻胶囊位。这几乎可以肯定是为了规避
**用户上传教材内页的版权风险**和 **OCR 识别错误导致的教学误导**。
我们做同类功能时同样会撞上这两条，需要在 PRD 里正面处理，不能忽略。

## 我们的差异化机会（滚动累积）

1. **上传的材料必须成为一等公民词书**——直接进入背诵与复习循环，而不是像竞品那样
   降级成一个只能听的播放器。这是用户最核心的诉求，也是竞品最大的空档。
2. **支持 Excel / PDF / 图片三种入口**，竞品只有图片。
3. **词根词缀聚类**用在高考 3500 词上，比竞品面向小学的自然拼读更有价值。
4. 识别结果**必须可人工纠错**（家长审核），这既是质量保证也是免责手段。
