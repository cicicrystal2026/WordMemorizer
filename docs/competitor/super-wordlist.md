## 第 1 批（5 张）：拍照阅读模块 + 主页信息架构

### 1.1 主页（单词书 Tab）

底部导航共四个 Tab：**基础手册 / 单词书 / 计划 / 我的**，当前停在「单词书」。

页面自上而下：

| 区域 | 内容 | 说明 |
| --- | --- | --- |
| 顶部 | `搜索单词` 输入框 + `切换教材` 按钮 | 词库以**教材版本**为组织单位 |
| 主视觉 | 3D 书本封面「北京版」，副标题「北京版三年级下（新课标版）」 | 教材精确到 **版本 + 年级 + 学期 + 课标** |

### 1.2 「统计式学习」——值得借鉴的一点

三个入口分别是 **自然拼读、词根词缀、音标组**。它们不是新词库，而是把同一册词
按**构词规律重新聚类**的三种视角：

- 自然拼读：按字母组合发音规律分组（适合低龄）
- 词根词缀：按 `pre-` `-tion` 等形态分组（适合高年级、高考）
- 音标组：按音素分组（服务发音训练）

命名为「统计式」说明分组是**从词库统计出来的**，不是人工编排。这是一个低成本、
高感知价值的功能——同一份词库免费多出三种学习路径。

对我们的启发：**高考 3500 词做词根词缀聚类，价值远大于低龄的自然拼读。**
我们已入库的 `data/gaokao-3500.json` 目前没有词根词缀字段，若要做需在补全阶段一并生成。

### 1.3 拍照阅读模块（本批重点）

这是竞品处理「用户自有材料」的通道，层级为：

```
拍照阅读
└── 阅读本（列表页，可有多本）        ← 「+ 添加阅读本」
    └── 单元 Unit1 / Unit2 …（Tab 横向排列）  ← 「+ 添加单元」
        └── 拍照导入（一个大按钮占位）
            └── 动作面板：拍照 / 从手机相册选择 / 取消
```

**阅读本列表页**：书本卡片（封面显示 `ENGLISH` + 书名 `11`），底部通栏
`+ 添加阅读本`；右上角 `?` 帮助 + 编辑图标（管理/删除）。第三张截图是同一页面的
**空状态**——白板一块，没有任何引导插图或说明文案。

**单元页**：
- 顶部：返回、书名 `11`、`⚠ 免责声明` 胶囊、右上角九宫格图标（推测为视图切换）
- 次级：`Unit1` 下划线选中态 + `+ 添加单元`
- 主体：`拍照导入` 大按钮
- **底部常驻播放条**：`1.0x` 倍速 / 上一条 / 播放 / 下一条 / `EN中` 语言切换

### 1.4 从这批截图能确认的三件事

**① 拍照导入的产物是「可播放的音频序列」，不是「可学习的单词」。**
底部播放条在**尚未导入任何内容时就已常驻**，说明单元页的本质是一个播放器。
`EN中` 切换推断为「只读英文 / 英中对照朗读」，`1.0x` 为语速。也就是说，这个模块
解决的是**跟读和磨耳朵**，而不是把拍下来的词纳入背诵体系。

**② 拍照阅读与主词库是两套平行体系，不打通。**
它挂在「单词书」页的四个快捷卡片里，是个附属工具。用户拍进去的词
**不会**进入主页那个「已学 48 / 未学 102」的进度环，也进不了 `学单词` / `去复习`
的循环。这是竞品的**结构性缺陷**。

**③ 只支持拍照和相册，不支持 Excel / PDF。**
动作面板只有两项。用户的孩子拿到的可能是老师发的电子表格或打印讲义，竞品覆盖不了。

### 1.5 「免责声明」说明的问题

单元页专门给免责声明留了一个常驻胶囊位。这几乎可以肯定是为了规避
**用户上传教材内页的版权风险**和 **OCR 识别错误导致的教学误导**。
我们做同类功能时同样会撞上这两条，需要在 PRD 里正面处理，不能忽略。

## 第 2 批（5 张）：拍照识别完整链路

### 2.1 链路还原

```
拍照导入 → 应用内相机 → 拍摄确认（X / ✓） → 智能识别中(9%)「请勿退出」 → 词条卡片列表
```

**① 应用内自建相机**（非系统相机）
顶部：返回、闪光灯开关、设置齿轮；底部：`W / 1x / 2x / 3.5x / 10x` 变焦档、
快门、前后摄切换。给了变焦说明他们知道用户常在**较远距离拍整页**。

**② 拍摄确认页**
只有 `X` 取消和 `✓` 确认两个操作，**没有裁剪框、没有透视校正、没有旋转**。
拍歪了只能重拍。

**③ 识别中**
`智能识别中，请勿退出...(9%)` —— 带百分比进度。「请勿退出」说明识别过程
**绑定前台、不可后台化**，退出即中断。见 2.4。

**④ 结果页**：竖向卡片列表，每张卡片两行 + 一行免责小字。

### 2.2 被识别的原始材料（重要）

拍的是**电脑屏幕上显示的扫描版 PDF**——「斯坦英语 - Unlock Your World with English」
第 121 页，双栏排版，编号 175–232，格式为 `175. indicate v.表明`。

这是个**极端不利的 OCR 场景**：拍屏幕（摩尔纹 + 反光 + 低对比度）、双栏、
带手写圈注。而识别结果准确——左栏 179–184（influence / initiative / innovation /
insight / inspire / install）与右栏 227–232（motivate / mutual / neglect /
nevertheless / notion / novel）都与原页逐条吻合。

可以确认他们做对的三件事：
- **双栏阅读顺序正确**：先左栏从上到下，再右栏，没有横向串行
- **序号被剥离**：`175.` 这类编号没有进入词条
- **抗屏摄干扰**：摩尔纹和反光没有击穿识别

这条基线要记住：**我们的识别质量至少要达到这个水平**，否则没有替换理由。

### 2.3 结果卡片的结构与缺陷

单张卡片：

```
influence v/n.影响          ← 第一行：原文识别结果（词 + 词性 + 中文）
影响                        ← 第二行：AI 解析出的中文释义
                内容由 AI 生成,仅供参考   ← 每张卡片都有
```

`novel adj.新颖的 n.小说` → 第二行归一化为 `新颖的；小说`，说明第二行确实经过
AI 解析和标点归一，不是简单复制。但在绝大多数词条上，**两行内容几乎完全重复**
（`影响` / `影响`、`创新` / `创新`），视觉上是纯冗余。

更关键的缺失：

- **没有音标**——卡片只有词形、词性、中文，与我们从 PDF 解析出的底库缺口一致
- **没有例句、没有词组**
- **看不到任何编辑入口**——不能纠正识别错误，只能被告知「仅供参考」

### 2.4 三个架构层面的观察

**① 识别是前台阻塞的。**
「请勿退出」+ 百分比进度 = 任务与前台生命周期绑定。拍一页要等，拍十页大概率
只能一页一页来。**我们应该做成服务端异步任务**，提交后可以退出，完成推送通知。

**② 出现了麦克风——但只在「当前项」上。**
结果页中 `insight n.洞察力` 整张卡片文字变**橙色高亮**，同时卡片右下角浮出一个
**麦克风按钮**；其余卡片没有。结合底部播放条，推断交互是：
顺序播放 → 播到哪张卡片哪张高亮 → 在当前卡片上可以录音跟读。

**这是全产品第一次出现录音入口。** 但目前只能确认「能录」，
**不能确认是否有评分/发音诊断**。这是后续批次要重点确认的（见待确认项）。

**③ 手写圈注被完全忽略。**
原页上 180、188、191、195、201、202、204、205、206、208、210、211、212、214、
216、219、227 等条目被笔圈了出来——这显然是使用者标记的重点词。
但结果列表里 179（未圈）和 180（圈了）一视同仁地全部导入，圈注没有被当作任何信号。

**这是一个明确的产品机会**，见下方差异化第 5 条。

### 2.5 顺带确认

拍的是高考词汇材料（编号已到 232，词汇难度为 legitimate / literacy / mediate 一档），
与用户给的 3500 词 PDF 属于同一学段。**我们选高考 3500 词作底库是对的。**

## 我们的差异化机会（滚动累积）

1. **上传的材料必须成为一等公民词书**——直接进入背诵与复习循环，而不是像竞品那样
   降级成一个只能听的播放器。这是用户最核心的诉求，也是竞品最大的空档。
2. **支持 Excel / PDF / 图片三种入口**，竞品只有图片。
3. **词根词缀聚类**用在高考 3500 词上，比竞品面向小学的自然拼读更有价值。
4. 识别结果**必须可人工纠错**（家长审核），这既是质量保证也是免责手段。
   竞品用「内容由 AI 生成,仅供参考」把风险转嫁给用户，我们应该用「可编辑」把它解决掉。
5. **识别手写圈注，作为重点词信号**（第 2 批发现）。老师或家长在讲义上圈出的重点，
   是现成的、高质量的优先级标注。竞品把这个信号整个丢掉了。
   实现上并不难——多模态模型可以直接被要求「标出哪些条目带手写圈注」。
6. **服务端异步识别**，替代竞品的前台阻塞式「请勿退出」。
7. **补齐音标**——竞品的拍照词条同样没有音标，而音标是听写和发音训练的前提。
