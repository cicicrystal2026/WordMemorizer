## 八、建议顺序

| 优先级 | 内容 | 理由 |
| --- | --- | --- |
| **P0** | 3.1 落后补救 | 已上线功能的缺陷，直接影响能否坚持下来 |
| **P0** | M4 内容补全（4.1–4.4） | 当前词条只有词+释义，体验单薄；且 M5 依赖音标 |
| P1 | 6.4 遮盖自测 | 成本极低，立刻提升练习密度 |
| P1 | 3.3 按掌握度分级出题 | 复习量大时每词三关太重 |
| P2 | M5 发音 | 差异化能力，但依赖 M4 的音标 |
| P2 | M2 图片识别 | 最难；Excel/PDF 已能覆盖当前材料 |
| P3 | M6 PWA / 离线 | 体验优化，非阻塞 |
| P3 | 6.10 设置页 | 目前无必须设置项 |

**M2 排在后面的理由**：孩子的 400 词已能通过 Excel 或含文本层的 PDF 导入，
图片识别是「更方便」而非「不可替代」。而 M4 缺失会让每一次背诵都打折扣。
