## 建议的任务切分顺序

按「解除阻塞的程度」排，不是按 PRD 章节顺序：

| 批次 | 内容 | 编号 | 理由 |
| --- | --- | --- | --- |
| **A** | 遮盖自测、答错重现、按掌握度出题、结算分项 | 34–38 | 纯前端，无外部依赖，立刻提升练习质量 |
| **B** | 词条详情页 + 编辑 + `edited_by_user` | 50, 51, 72 | 为 M4 准备承载界面 |
| **C** | M4 内容补全 | 81–87 | 解除对音标的依赖，M5 才能做 |
| **D** | 词库手势、收藏、标签、错词本、上次学习 | 40–49 | 体验完善 |
| **E** | 设置页、退出登录、字号、宽屏 | 67, 78–80 | 补齐信息架构 |
| **F** | M5 发音 | 52–59 | 差异化能力，依赖 C |
| **G** | M2 图片识别 + 审核 | 1–2, 7–8, 10–12, 16–22 | 最难；Excel/PDF 已覆盖当前材料 |
| **H** | PWA + 本地优先 | 73–77 | 体验优化，非阻塞 |

**批次 A 最适合先交给 DeepSeek**：四个功能点都是纯逻辑 + 前端，
可以写出明确的测试，且互不依赖，能并行验证交接流程的稳定性。
