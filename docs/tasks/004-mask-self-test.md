# 任务 004：遮盖自测（功能点 #37）

**优先级**：P1
**类型**：界面
**前置**：无（与 002/003 互不依赖，可并行）
**必须改动的文件**：`app/library/library-client.tsx`
**可能改动**：`lib/constants.ts`（若需新增常量）

## 背景

PRD 5.4 把这一条标为「成本极低、价值极高」：不进学习流程，
在词库列表里直接遮住一栏，自己对着回想，想不起来点一下看答案。
孩子在饭桌上、车上刷两分钟就能用，是使用频次最高的轻量形态。

竞品「超级单词表」有这个功能，但它的词库页是只读的；
我们的词库页已经带掌握度改判，遮盖模式叠上去正好补齐「随手自测」。

## 要做的事

在 `app/library/library-client.tsx` 的筛选条下方，加一排三选一：

```
遮盖： [ 不遮 ]  [ 遮英文 ]  [ 遮中文 ]
```

| 模式 | 行为 |
| --- | --- |
| `none` | 现状，两栏都显示 |
| `word` | 单词位置显示占位条，释义正常显示 |
| `meaning` | 释义位置显示占位条，单词正常显示 |

### 交互细节

- 占位条是一个与文字等高的灰色圆角块（用 `var(--purple-soft)`），
  **宽度按被遮内容的字数估算**，不要用固定宽度——
  等宽的方块会泄露「这些词一样长」的信息，也不好看
- 点占位条 → 只揭开这一条，再点收回。揭开状态存在组件内的 `Set<number>`
- 切换遮盖模式时清空已揭开的集合
- 换筛选（`filter`）时保留遮盖模式，清空已揭开的集合
- 遮盖模式下，点行本身仍然展开掌握度改判面板——两个交互不要打架：
  **占位条上的点击不冒泡到行**（`e.stopPropagation()`）

### 记住选择

用 `localStorage` 存遮盖模式，键名 `wm_mask_mode`。
读取必须放在 `useEffect` 里，不能在渲染期读——
服务端渲染时没有 `localStorage`，渲染期读会造成 hydration 不一致。
首帧一律按 `none` 渲染，挂载后再切到存储值。

### 无障碍

占位条要有 `aria-label`（如「点击显示单词」），并且是真正的 `<button>`，
不要用带 `onClick` 的 `<span>`。

## 测试

这个任务以人工验收为主，但请补一个纯函数测试：把「按字数估算占位条宽度」
抽成一个导出的纯函数（例如 `maskWidth(text: string): string`，返回 `em` 值），
写进 `tests/mask-width.test.ts`，覆盖：空串、纯英文、纯中文、中英混排。

中文字符按 1em、英文字母按 0.55em 估算，结果夹在 `[2em, 12em]` 之间。
