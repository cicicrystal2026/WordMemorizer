# 学习材料分析

基于用户提供的 7 张真实拍摄样本（2026-08-02）。

## 材料来源

《斯淇英语 · Unlock Your World with English》纸质书，第 118–124 页。
样本**完整覆盖编号 1–400 的核心词汇表**，词表至 400（`wonder`）结束。

**这 400 个词就是孩子本月的学习目标。** 负荷测算见 `docs/study-plan-analysis.md`。

> 注：竞品截图中被拍摄的正是同一本书的第 121 页（编号 175–232，逐条吻合）。
> 用户此前用同一份材料测试过竞品。

## 版式特征

```
斯淇英语 · Unlock Your World with English        ← 页眉
 1. accumulate v.积累          30. circumstance n.环境；情况
 2. accurate adj.准确的        31. civilization n.文明
 …                            …
29. characteristic n.特征 adj.典型的   58. core n.核心 adj.核心的
                    119                          ← 页码
```

| 特征 | 说明 |
| --- | --- |
| 栏数 | 双栏 |
| 每栏条数 | **29 条** |
| 每页条数 | **58 条**（末页 52 条，因词表在 400 结束） |
| 编号 | **跨页连续**，1 → 400 |
| 条目格式 | `序号. 单词 词性.中文释义` |
| 多词性 | 同条并列，如 `advocate v.提倡 n.倡导者`、`collapse v./n.崩溃` |
| 多义项 | 以 `；` 分隔，如 `acknowledge v.承认；致谢` |
| 手写标注 | 本批样本**无** |

## 编号是天然的完整性校验机制

这是本次分析最有价值的发现。

因为编号连续且每页固定 58 条，识别结果可以**用确定性规则自动验收**，
而不依赖模型自我评估：

| 故障 | 检测方式 |
| --- | --- |
| 漏识别 | 序号断号 |
| 重复识别 | 序号重复 |
| 串栏（读串到另一栏） | 序号顺序错乱 |
| 邻页内容混入 | 序号超出本页应有区间 |
| 整页不完整 | 条数 ≠ 58 |

**因此识别时必须要求模型连同序号一起输出**，序号是校验凭据，
不能像竞品那样在识别阶段就剥离丢弃。

竞品完全没有利用这一信号。

## 拍摄条件的实际挑战

样本反映的是真实使用场景，非理想条件：

| 问题 | 严重程度 | 说明 |
| --- | --- | --- |
| **书页弯曲** | 高 | 靠书脊一侧文字呈弧线，第 119、121 页最明显 |
| **透视变形** | 中 | 手持拍摄，页面呈梯形 |
| **背面透印** | 中 | 反面文字隐约可见，第 121 页右侧尤甚 |
| **邻页入镜** | 中 | 对开页内容进入画面，可能被误识别 |
| **水印** | 低 | 首页有斜向水印压在正文上 |
| **背景杂物** | 低 | 地砖、椅子等入镜 |

**邻页入镜风险最高**——混入的条目会破坏序号连续性，
但恰好被上一节的编号校验捕获。

相较竞品样本（拍电脑屏幕上的扫描件，含摩尔纹、反光、手写圈注），
本材料为**印刷体、高对比度、无涂改**，识别难度更低。

## 与 3500 词底库的重合度：仅 49.5%

对全部 400 个词与 `data/gaokao-3500.json` 做交叉核对：

```
命中 198 / 400 = 49.5%
未命中 202 个
```

原因是两份材料定位不同：

| | 高考 3500 词 PDF | 斯淇英语核心词 |
| --- | --- | --- |
| 收词特征 | 含 `cat` `dog` `apple` `ink` `inn` `insect` 等基础词 | `empathy` `legitimate` `literacy` `mediate` `prevail` 等高阶词 |
| 定位 | 大纲基础词汇 | 高频提分词 |

另经核实，该 PDF 本身存在收词缺口——以下常见词均不在其中：

```
maintain  issue  image  factor  core  current  critical  feature  impact  identify
```

（M 段由 `mainland` 直接跳至 `major`，`maintain` 缺失。）

### 对架构的影响

**原设想的「词库匹配为主、AI 生成兜底」不成立。**
49.5% 的命中率意味着：

- **AI 生成是补全音标、例句、词组的主路径**
- 词库匹配退为辅助：命中时可用于**交叉校验 AI 结果**，提高可信度
- 未命中的 202 个词恰是高频高阶词，AI 生成质量有保障（词频高、释义稳定）

底库仍有价值，但角色从「数据源」变为「校验参照」。

## 对识别方案的要求

综合以上，识别管线需满足：

1. **输出必须包含原始序号**，用于完整性校验
2. **必须正确处理双栏阅读顺序**（先左栏到底，再右栏）
3. **必须能容忍书页弯曲与透视变形** —— 传统 OCR 在此类形变上表现差，
   多模态模型更稳健
4. **必须排除邻页内容** —— 可通过序号区间校验兜底
5. **必须支持人工纠错** —— 见竞品分析结论，识别错误对学习的危害大于识别不全

## 导入流程的含义

全书核心词表共 **400 词、约 7 页**。这意味着：

- **一次导入即可覆盖孩子整月的学习量**，不是零散、频繁的操作
- 导入流程应支持**多页批量上传**，而非竞品那种一页一次、还要「请勿退出」
- 单次任务规模约 7 张图、400 个词条，服务端异步处理是合理选择
