# 后续产品：小学生版背单词工具

**状态**：未启动，待当前高考版做好后再议
**记录日期**：2026-08-02

## 缘起

当前产品（高考版）在 `docs/prd.md` 中明确砍掉了五项功能。
砍掉的理由是**它们对高考生无效**，而不是它们没价值——
这五项恰恰是**小学阶段的教学主线**。

因此这五项在小学版中应从「不做」翻转为「核心」。

## 五项功能：为何现在砍、将来做

| 功能 | 高考版砍掉的理由 | 小学版的价值 |
| --- | --- | --- |
| **自然拼读** | 高中生解码能力已过关，不是瓶颈 | 见词能读、听音能写，是小学英语的核心能力 |
| **音素口型视频** | 同上 | 发音起步阶段最有效的教学手段 |
| **四线三格书写** | 高中生早已掌握字母书写 | 小学要练字母形态与书写规范 |
| **真人录音库** | 用户上传词无法覆盖，只能全量 TTS | 小学词汇量小、词表固定，真人录音可覆盖且质量远胜 TTS |
| **教材版本体系** | 词从用户上传材料来，不需要教材树 | 小学严格跟教材走，版本+年级+学期是刚需 |

## 可以直接沿用的部分

以下与学段无关，两个产品通用：

- 导入管线（图片 / PDF / Excel 分流、序号完整性校验、手写圈注识别）
- 内容补全管线（AI 生成 + 人工审核）
- 计划引擎（按截止日倒算、负荷曲线、落后补救）
- 复习算法（SM-2 变体、掌握度四级、手动改判）
- 发音评测（音素级；小学版应改为美音或按教材要求）
- 本地优先架构

**若第一步的 API 层按决策 001 写得足够薄**（业务逻辑全在 `app/api/*`），
小学版可以复用同一套后端，只换前端与内容策略。

## 需要重新决策的点

- [ ] 口音：高考版定 en-GB；小学版需按孩子所用教材确定（人教版多为美音）
- [ ] 使用范围：是否仍为自用，还是要面向更多用户（影响账号体系与合规）
- [ ] 真人录音库的来源与成本
- [ ] 教材词库的获取方式（版权问题比用户自有材料敏感）
- [ ] 未成年人个人信息保护：若面向公众，合规要求远高于自用
