# 产品需求文档

第一步（Web 端）。以 `docs/decisions/`、`docs/architecture.md`、
`docs/material-analysis.md`、`docs/study-plan-analysis.md` 为前提，不重复其结论。

---

## 一、产品定位

**把孩子手上的任何单词材料，变成一套能真正背下来的学习计划。**

与市面产品的根本差异：市面产品以**自家词库**为中心，用户材料是附属工具
（竞品的拍照阅读只能听，进不了学习循环）。本产品以**用户材料**为中心，
导入的词就是一等公民。

## 二、目标与非目标

### 目标

1. 图片 / PDF / Excel 三种材料都能准确导入，识别结果可人工纠正
2. 按「何时背完」倒算计划，并让孩子看得见每日真实负荷
3. 背诵闭环有效：认得出、拼得对、**读得准**、用得上
4. 手写圈注自动成为重点词，获得更高的复习权重

### 非目标（明确不做）

| 不做 | 原因 |
| --- | --- |
| 注册 / 找回密码 / 多租户 / 付费 | 只给自家孩子用（决策 003） |
| 自然拼读、音素口型视频、四线三格书写 | 面向小学解码训练，高考场景无效 |
| 真人录音库 | 用户上传词无法覆盖，全量 TTS 是唯一可行路线 |
| 教材版本体系 | 词从用户材料来，不需要教材树 |
| 排行榜 / 社区 / 分享 | 单用户 |

## 三、用户与场景

**使用者**：一名高中生。**管理者**：家长（导入材料、审核识别结果、看进度）。

三个真实场景：

| 场景 | 频率 | 描述 |
| --- | --- | --- |
| **建库** | 月度 | 家长拍 7 页照片或上传 Excel，导入 400 词，审核识别结果 |
| **每日背诵** | 每天 | 孩子完成当日队列（新词 + 到期复习），含跟读 |
| **查漏** | 周度 | 家长看战报，孩子练重点词与错词 |

底部四个 Tab：

```
今日        词库        战报        设置

 ├ 今日队列   ├ 词书列表   ├ 进度总览   ├ 计划设置
```

## 五、功能规格

### 5.1 导入（M1 / M2）

#### 5.1.1 入口与格式

设置页 → 导入材料。支持 **拍照 / 相册 / 文件**（PDF、xlsx、csv）。
可**一次选多个文件**（材料实测约 7 页）。

#### 5.1.2 分流处理

按 `docs/architecture.md` 第一节分流。用户无需感知走了哪条路径，
但**进度提示要区分**：

- Excel / 含文本层 PDF：「正在解析…」（秒级）
- 图片 / 扫描件：「正在识别第 3/7 页…」（分钟级）

#### 5.1.3 异步任务

上传后立即返回，**用户可以关闭页面**。任务完成后在「今日」页顶部出现提醒。
原始文件存 R2，识别有误可重跑而不必重拍。

#### 5.1.4 Excel 列映射确认

解析后展示前 5 行，让用户确认列语义：

```
第 1 列 → 序号      [下拉可改]
第 2 列 → 单词      [下拉可改]
第 3 列 → 词性      [下拉可改]
第 4 列 → 中文释义   [下拉可改]
```

确认一次后，同结构文件自动套用。

#### 5.1.5 完整性校验结果展示

识别完成后，先展示校验报告，**再进入审核**：

```
✓ 已识别 400 词，编号 1–400 连续无缺
⚠ 第 3 页缺 3 条（编号 142、157、160）  [重拍此页]
⚠ 12 条置信度偏低，已排入审核队列前列
🚩 识别到 47 条手写圈注，已标为重点词
```

### 5.2 审核（M2）

**这是必需环节，不是可选。** 错误内容比缺失内容危害更大。

- 列表逐条展示：**序号、单词、词性、释义、是否重点词**
- 所有字段**可编辑**
- 排序：低置信度 → `needs_review`（与底库分歧）→ 其余
- 支持**跳过审核直接开始学**，但未审核词条在学习界面带标记
- 批量操作：全部确认、删除选中

### 5.3 计划（M3）

#### 5.3.1 创建计划：反向倒算

```
选择词书    [斯淇英语核心词 400]
目标完成日  [2026-08-31]        ← 用户输入这个
─────────────────────────
每天新词    34 个               ← 系统倒算，可微调
预计负荷    峰值 170 条/天（第 12 天）
```

**约束**：每日新词量 ≥ 总词数 ÷ (周期 − 最长复习间隔)。
低于下限时给出明确警告：

> 按每天 20 个，到 8 月 31 日会有约 100 个词的复习没做完。
> 建议每天至少 27 个。

#### 5.3.2 负荷曲线（必需）

创建计划时展示未来 30 天每日总量柱状图，标注：

- 「第 8 天起进入稳态，约 100 条/天」
- 「第 12 天学完全部新词，之后只剩复习」

**目的是建立预期。** 这是放弃率最高的时点。

#### 5.3.3 落后补救

当日未完成时，次日**不做简单顺延**，采用优先级截断：

- 按「距遗忘临界的远近」排序，当日只做最紧急的 N 条
- 其余顺延，并提示「已自动调整，今天仍是 N 条」
- 落后超过 3 天时，提示是否延长目标日期

**原则：保证每天的量可完成，优先于保证计划不变。**

### 5.4 学习流程（M1 / M5）

#### 5.4.1 新词首学：四关

沿用现有原型的分关思路，但**插入跟读**，并去掉小学向内容：

| 关卡 | 形式 | 通过条件 |
| --- | --- | --- |
| **① 认读** | 展示词形+音标+释义，播放 en-GB 发音 | 点击继续 |
| **② 跟读** | 录音，音素级评分 | 达到阈值或跳过（见 5.6） |
| **③ 认义** | 四选一（中文选项） | 答对 |
| **④ 拼写** | 听音 + 看中文，输入拼写 | 答对 |

答错的词当轮末尾重新出现一次。

#### 5.4.2 复习：按掌握度出题

| 掌握度 | 题型 |
| --- | --- |
| 生词 | 走完整四关 |
| 半熟 | 认义 + 拼写 |
| 熟悉 | 拼写 或 语境填空（随机） |
| 永久掌握 | 不出现在常规队列 |

#### 5.4.3 语境填空

用 AI 生成的例句挖空，四个词形选项。作为「熟悉」级的抽查题型。

#### 5.4.4 遮盖自测（采纳自竞品）

词库列表页提供遮盖开关：

- 无遮盖 / 遮英文（看中文回想英文）/ 遮中文（看英文回想中文）

成本极低、价值高。

#### 5.4.5 结算页

```
本组 20 词完成
认义 18/20    拼写 15/20    发音 16/20
待巩固 6 个
[继续下一组]  [今天到此为止]
```

### 5.5 词库管理（M1 / M3）

#### 5.5.1 词条列表

每条展示：**单词、音标、词性、中文、掌握度色条、学习次数**。
沿用竞品的「上次学习」角标标记续学断点。

#### 5.5.2 手势（采纳自竞品）

| 手势 | 操作 |
| --- | --- |
| **左滑** | 掌握度四级：生词 / 半熟 / 熟悉 / 永久掌握 |
| **右滑** | 删除 / 收藏 / 标记重点词 |
| 点击 | 进入词条详情 |

首次使用弹出操作说明，带「不再提示」。

#### 5.5.3 筛选

`🚩重点词` / 全部 / 已学 / 未学 / 错词 / 收藏。

#### 5.5.4 词条详情

```
indicate  /ˈɪndɪkeɪt/  🔊  🎤
v. 表明；指示
─────────────────
词组   indicate that…
例句   Recent studies indicate that…
       近期研究表明……
词根   in-(向内) + dic-(说) → 指出        ← 有则显示，无则隐藏
─────────────────
掌握度 熟悉    学习 7 次    下次复习 8月15日
[编辑]  [标为重点词]
```

**所有 AI 生成字段可编辑**（决策：不以免责声明替代纠错能力）。

### 5.6 发音（M5）

#### 5.6.1 TTS

统一 **en-GB**。音标同为英式，避免口音与音标不一致。
音频首次合成后缓存 R2。

#### 5.6.2 跟读评测

- 点麦克风 → 录音 → 音素级评分
- 结果展示：**总分 + 逐音素标色**（读错的音标红）
- 低于阈值可重录，**最多 3 次后允许跳过**——避免挫败感
- 阈值初始设 60 分，**上线后按孩子实际表现调**

#### 5.6.3 录音数据

**用完即弃**，只存分数与错音音素，不留原始音频（决策 002）。

### 5.7 战报（M3）

- 今日 / 本周 / 本月完成量
- 掌握度四级分布
- 连续天数
- **发音薄弱音素 TOP 5**（这是竞品没有的）
- 错词 TOP 10

### 5.8 访问控制（M1）

首次访问输入口令，Cookie 有效期 90 天。中间件校验。

## 六、数据规格

表结构见 `docs/architecture.md` 第六节。此处补充关键字段约束：

| 字段 | 约束 |
| --- | --- |
| `words.seq` | 保留原始序号，用于完整性校验，可空（Excel 无序号时） |
| `words.is_key` | 重点词，来自手写圈注或手动标记 |
| `words.needs_review` | 与底库分歧或低置信度，进审核队列 |
| `word_details.*` | AI 生成，全部可编辑；编辑后置 `edited_by_user=true`，重新生成时不覆盖 |
| `study_states.mastery` | 四级枚举 |
| `study_states.ease/interval/due_at` | SM-2 内部状态，不对用户暴露 |
| `users.id` | 单用户仍保留，为第二步小程序预留 |

## 七、非功能需求

| 项 | 要求 |
| --- | --- |
| 日常背诵 | **不依赖网络**，IndexedDB 本地完成 |
| 首屏 | 3 秒内可交互 |
| 导入 | 异步，可关页面；7 页图片 5 分钟内完成 |
| 响应式 | 手机优先，桌面端居中窄栏 |
| 无障碍 | 字号可调（采纳自竞品，成本极低） |
| API | 全部 `app/api/*` Route Handler，**禁用 Server Actions**（决策 001） |

## 八、里程碑与验收标准

| 阶段 | 内容 | 验收标准 |
| --- | --- | --- |
| **M1** | Excel/PDF 导入、数据模型、基础背诵、口令 | 用 Excel 导入 400 词并完成一组背诵 |
| **M2** | 图片识别、序号校验、圈注识别、审核界面 | 拍 7 页照片，识别 ≥95%，圈注正确标出，可纠错 |
| **M3** | 计划引擎、复习算法、掌握度四级、战报 | 设定 8/31 完成，系统倒算出 27–34，负荷曲线正确 |
| **M4** | AI 内容补全 | 400 词的音标/词组/例句全部生成且可编辑 |
| **M5** | TTS + 发音评测 | 跟读能拿到音素级反馈，错音标红 |
| **M6** | PWA + 离线 | 断网可完成当日队列，联网后同步 |

**M1 先做 Excel/PDF 而非拍照**：零 AI 成本、准确率高，最快跑通端到端，
先验证数据模型与学习流。图片识别最难，放在流程验证之后。

## 九、风险与未决

| 风险 | 应对 |
| --- | --- |
| 书页弯曲导致识别率不达标 | 序号校验兜底；提供「重拍此页」 |
| AI 生成例句有误导 | 强制家长审核 + 全字段可编辑 |
| 孩子被发音评分打击 | 3 次后可跳过；阈值上线后按实际表现调 |
| 负荷仍超孩子承受 | 优先级截断 + 提示延长周期 |
| 第二步小程序的 ICP 备案 | 已并行启动，见决策 001 |

### 未决事项

- [ ] 发音评测通过阈值的初始值（暂定 60，需实测）
- [ ] 复习间隔基线是否沿用 1/2/4/7/15
- [ ] 桌面端是否做双栏布局
- [ ] 词根助记的生成质量是否够用（需抽样评估）
